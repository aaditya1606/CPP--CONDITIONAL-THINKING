# C++ Conditional Statements Practice

This repository contains the C++ programs I have written while learning and practising conditional statements. I created these programs to improve my understanding of logic building and learn how to solve different problems using conditions.

## What I'm Practising

In this repository, I have covered problems related to:
- `if`, `else if` and `else` statements
- Nested conditional statements
- Logical operators (`&&`, `||`, `!`)
- Comparison operators
- Checking different conditions on numbers and characters
- Basic problem-solving and logic building

## Programs Included

Some of the problems I have worked on include:

- Checking whether a number is divisible by 5 or by both 3 and 5
- Checking whether numbers are in Arithmetic Progression (AP)
- Classifying characters
- Finding the corresponding day of the week
- Printing grades based on conditions
- Checking whether all digits of a number are distinct
- Finding the third angle of a triangle
- Checking whether an amount can be distributed evenly

There are more practice problems in the repository, and I will keep adding new ones as I learn.

## Why I Created This Repository

My main goal is to strengthen my C++ basics and get better at breaking problems into smaller steps before writing code. These programs are part of my regular coding practice, and each problem helps me understand conditional statements a little better.
